SQL Interview Questions & Answers – 2026
Q1. Write a SQL query to find the second highest salary from the Employees table.
Answer:

SELECT MAX(salary)
FROM Employees
WHERE salary < (SELECT MAX(salary) FROM Employees);
Q2. Write a SQL query to find the duplicate records in a table.
Answer:

SELECT name, COUNT(*)
FROM Employees
GROUP BY name
HAVING COUNT(*) > 1;
Q3. Write a SQL query to remove duplicate records from a table.
Answer:

DELETE FROM Employees
WHERE id NOT IN (
    SELECT MIN(id)
    FROM Employees
    GROUP BY name
);
Q4. Write a SQL query to find the top 5 highest salaries.
Answer:

SELECT *
FROM Employees
ORDER BY salary DESC
LIMIT 5;
Q5. Write a SQL query to find the Nth highest salary.
Answer:

SELECT DISTINCT salary
FROM Employees
ORDER BY salary DESC
LIMIT 1 OFFSET N-1;
Q6. Write a SQL query to fetch departments and their total salary expenditure.
Answer:

SELECT department_id,
       SUM(salary) AS total_salary
FROM Employees
GROUP BY department_id;
Q7. Write a SQL query to find employees who joined in the last 6 months.
Answer:

SELECT *
FROM Employees
WHERE joining_date >= CURRENT_DATE - INTERVAL 6 MONTH;
Q8. Write a SQL query to find employees who are not in any department.
Answer:

SELECT *
FROM Employees
WHERE department_id IS NULL;
Q9. Write a SQL query to find the total number of employees in each department.
Answer:

SELECT department_id,
       COUNT(*) AS total_employees
FROM Employees
GROUP BY department_id;
Q10. Write a SQL query to pivot data to show department-wise employee count.
Answer (SQL Server):

SELECT *
FROM (
    SELECT department, employee_id
    FROM Employees
) AS SourceTable
PIVOT (
    COUNT(employee_id)
    FOR department IN ([HR], [IT], [Sales])
) AS PivotTable;
Q11. Write a SQL query to unpivot data from a table.
Answer (SQL Server):

SELECT EmployeeID,
       Department,
       Salary
FROM EmployeeSalary
UNPIVOT
(
    Salary FOR Department IN (HR, IT, Sales)
) AS UnpivotTable;
Q12. Write a SQL query to find month-over-month revenue growth.
Answer:

SELECT month,
       revenue,
       revenue - LAG(revenue)
       OVER(ORDER BY month) AS growth
FROM Sales;
Q13. Write a SQL query to find the running total of sales by date.
Answer:

SELECT sale_date,
       amount,
       SUM(amount)
       OVER(ORDER BY sale_date) AS running_total
FROM Sales;
Q14. Write a SQL query to find gaps in a sequence of numbers.
Answer:

SELECT number + 1 AS gap_start
FROM Numbers
WHERE number + 1 NOT IN (SELECT number FROM Numbers);
Q15. Write a SQL query to find the longest streak of consecutive login days for a user.
Answer:

SELECT user_id,
       MIN(login_date),
       MAX(login_date),
       COUNT(*) AS streak
FROM Logins
GROUP BY user_id;
Q16. Write a SQL query to find the first login date of each user.
Answer:

SELECT user_id,
       MIN(login_date)
FROM Logins
GROUP BY user_id;
Q17. Write a SQL query to find the last purchase of each customer.
Answer:

SELECT customer_id,
       MAX(purchase_date)
FROM Orders

Q18. Write a SQL query to find customers who bought in all months.
Answer:

SELECT customer_id
FROM Orders
GROUP BY customer_id
HAVING COUNT(DISTINCT MONTH(order_date)) = 12;
Q19. Write a SQL query to find products that were never ordered.
Answer:

Answer:

Q50. Write a SQL query to generate a series of dates between two given dates.
Answer (MySQL 8+):

WITH RECURSIVE Dates AS
(
SELECT '2026-08-01' AS dt
UNION ALL
SELECT DATE_ADD(dt,INTERVAL 1 DAY)
FROM Dates
WHERE dt<'2026-08-10'
)
SELECT *
FROM Dates;






DIFFERENCE BETWEEN SQL TOPICS
Q1. Difference between SQL and MySQL
SQL	MySQL
SQL (Structured Query Language) is a language used to manage databases.	MySQL is a Relational Database Management System (RDBMS).
It is used to write queries like SELECT, INSERT, UPDATE, DELETE.	It executes SQL queries and stores data.
SQL is a standard language.	MySQL is software developed by Oracle.
SQL cannot store data by itself.	MySQL stores, retrieves, and manages data.

Example:

SQL → SELECT * FROM Employees;
MySQL → Software that executes the above query.
Q2. Difference between SQL and PL/SQL
SQL	PL/SQL
SQL is a query language.	PL/SQL is Oracle's procedural extension of SQL.
Executes one statement at a time.	Executes blocks of code.
No loops or conditions.	Supports IF, LOOP, WHILE, FOR, Exception Handling.
Used for data manipulation.	Used for writing procedures, functions, triggers.
Q3. Difference between SQL and NoSQL
SQL	NoSQL
Relational database	Non-relational database
Stores data in tables	Stores JSON, Key-Value, Graph, Documents
Fixed schema	Flexible schema
Uses SQL language	Does not use standard SQL
Vertical scaling	Horizontal scaling

Examples

SQL → MySQL, Oracle, PostgreSQL
NoSQL → MongoDB, Cassandra, Redis
Q4. Difference between DBMS and RDBMS
DBMS	RDBMS
Stores data	Stores related data in tables
Relationships are not mandatory	Supports relationships
Less secure	More secure
No foreign key support	Supports foreign keys
Example: File System	Example: MySQL, Oracle
Q5. Difference between CHAR and VARCHAR
CHAR	VARCHAR
Fixed length	Variable length
Faster	Slightly slower
Wastes space	Saves space
Pads unused spaces	No extra spaces

Example:

CHAR(10)

Stores "ABC" as

ABC_______

VARCHAR(10)

Stores only

ABC
Q6. Difference between Primary Key and Foreign Key
Primary Key	Foreign Key
Uniquely identifies a row	Links two tables
Cannot contain NULL	Can contain NULL
Only one primary key	Multiple foreign keys allowed
Must be unique	Duplicate values allowed
Q7. Difference between WHERE and HAVING
WHERE	HAVING
Filters rows	Filters groups
Used before GROUP BY	Used after GROUP BY
Cannot use aggregate functions	Can use aggregate functions

Example

SELECT *
FROM Employee
WHERE salary>50000;
SELECT department,
COUNT(*)
FROM Employee
GROUP BY department
HAVING COUNT(*)>5;
Q8. Difference between Subquery and Correlated Subquery
Subquery	Correlated Subquery
Executes once	Executes for every row
Independent	Depends on outer query
Faster	Slower
Q9. Difference between INNER JOIN and OUTER JOIN
INNER JOIN	OUTER JOIN
Returns matching rows	Returns matching + non-matching rows
Most commonly used	LEFT, RIGHT, FULL OUTER
Q10. Difference between DELETE, TRUNCATE and DROP
DELETE	TRUNCATE	DROP
Deletes rows	Removes all rows	Deletes entire table
WHERE allowed	WHERE not allowed	Table removed completely
Can rollback	Cannot rollback (most DBs)	Cannot rollback
Structure remains	Structure remains	Structure removed
Q11. Difference between UNION and UNION ALL
UNION	UNION ALL
Removes duplicates	Keeps duplicates
Slower	Faster
Q12. Difference between SUM() and COUNT()
SUM()	COUNT()
Adds numeric values	Counts rows
Numeric column only	Any column

Q21. What is a Correlated Subquery?

Q22. What are the ACID Properties?

A – Atomicity: Either all operations complete or none do.

C – Consistency: Database remains in a valid state before and after the transaction.

I – Isolation: Concurrent transactions do not interfere with each other.

D – Durability: Once committed, data is permanently saved even if the system fails.

Q23. What is a Stored Procedure?

A stored procedure is a named block of SQL statements that can accept parameters, perform operations, and be executed whenever needed.

Advantages:

Improves performance
Reduces code duplication
Enhances security
Q24. What is a Stored Function?

A stored function is similar to a stored procedure but must return a single value and can be used within SQL statements.

Difference from Procedure:

Function returns a value.
Procedure may or may not return values.
Q25. What is a Trigger?

UPDATE
DELETE
Q26. What is a Cursor?

Types:

Q27. What is an Exception? What are its types?

An exception is an error or unexpected event that occurs during SQL or PL/SQL program execution.

Types of Exceptions:

Predefined Exceptions – Built-in exceptions (e.g., NO_DATA_FOUND, ZERO_DIVIDE)
Non-Predefined Exceptions – Oracle-defined exceptions that require explicit handling.
User-Defined Exceptions – Custom exceptions created by the programmer.










One-Line Interview Answers
SQL vs MySQL: SQL is a query language; MySQL is an RDBMS that uses SQL.
Primary Key vs Foreign Key: A primary key uniquely identifies a record; a foreign key links tables.
DELETE vs TRUNCATE vs DROP: DELETE removes selected rows, TRUNCATE removes all rows while keeping the table, and DROP deletes the entire table.
WHERE vs HAVING: WHERE filters rows before grouping; HAVING filters groups after GROUP BY.
GROUP BY: Groups rows with the same values for aggregate calculations.
JOIN: Combines rows from two or more tables based on a related column.
Subquery: A query inside another query.
Correlated Subquery: A subquery that depends on the outer query and executes for each row.
RANK vs DENSE_RANK: RANK() skips numbers after ties; DENSE_RANK() does not.
Normalization: Organizes data to reduce redundancy and improve integrity.
ACID: Atomicity, Consistency, Isolation, and Durability ensure reliable transactions.
Stored Procedure: A reusable block of SQL statements that performs tasks.
Function: Similar to a procedure but always returns a value.
Trigger: A program that automatically runs when INSERT, UPDATE, or DELETE events occur.
Index: A database object that speeds up data retrieval.
CTE: A temporary named result set used to simplify complex queries.
Aggregate Functions: Functions such as SUM(), COUNT(), AVG(), MAX(), and MIN() that operate on multiple rows and return a single result.

49. Difference Between WHERE and GROUP BY
WHERE	GROUP BY

50. Difference Between HAVING and WHERE

WHERE filters rows.

HAVING filters groups.

51. Difference Between INNER JOIN and OUTER JOIN

INNER JOIN returns only matching rows.

OUTER JOIN returns matching and non-matching rows.

52. Difference Between LEFT JOIN and RIGHT JOIN

LEFT JOIN returns all records from the left table.

RIGHT JOIN returns all records from the right table.

53. Difference Between Subquery and Correlated Subquery

Subquery executes once.

Correlated subquery executes for every row.
